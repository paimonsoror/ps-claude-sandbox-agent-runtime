The sentence, assembled

Read it as two halves. The control plane owns the life of a sandbox: declare it, keep warm capacity, bind a session to one, route to it, pause, snapshot, delete. The substrates own what a session can touch while it runs. The two providers the sentence names are not peers: the microVM is a where (a kernel boundary), OpenShell is a what (a policy and credential boundary inside the sandbox), and OpenShell can run on a microVM. No product ships the combination on-premises today.

What carries over unchanged

image

The sandbox image

srt + Claude Code + ant, non-root, read-only. It is what a SandboxTemplate would reference; nothing in it assumes a Deployment.

policy

srt settings.json

The policy document. allowWrite maps to Landlock paths, allowedDomains to network_policies, deniedResolvedAddresses to metadata denies, field by field.

network

Per-sandbox network policy

What agent-sandbox calls its managed NetworkPolicy mode: no inter-sandbox traffic, egress to the public names only.

records

GitOps and ADRs

Delivery and decisions do not change; ADR-0015 records the direction and its gates.

The path

  1. Keep today's chart for the owner's workspacesThey are long-lived developer machines; a lifecycle API adds nothing for them.
  2. Control plane first: per-session Managed Agents sandboxesInstall kubernetes-sigs/agent-sandbox on the k3s node. Replace the always-on worker with a poller that creates one SandboxClaim per work item from a SandboxTemplate built from this image. Evaluate the warm pool. This is the on-premises half of the sentence with the substrate we already have.gate: a controller install; its own ADR and app-of-apps entry
  3. Substrate second: a microVM RuntimeClassWhen a KVM-capable node exists, add Kata or a libkrun-backed runtime to the template and run srt in weak mode inside it. This also closes the Pod Security Standard restricted gap.gate: hardware with KVM (nested virtualisation or a second node)
  4. Policy layer evaluation: OpenShell vs srtCompare on the controls-matrix rows it would change: credential brokering, per-binary L7 egress, policy prover. Switch only if it wins there and Anthropic lists it as a provider; otherwise pursue srt's own credential masking and TLS termination.gate: OpenShell release on Anthropic's provider list

One-line answer for the principal engineer

Same substrate shape (hardened image plus a policy document, deny-all egress, no credentials in git), the control plane and the kernel boundary still to come, each blocked by one concrete thing: a controller install, and a node with KVM.
