Kubernetes

User namespaces and Pod Security

FactSourceUsed by
User namespaces (hostUsers: false) are GA in v1.36; need kernel 6.3+, containerd 2.0+, idmap-capable volumes; NFS unsupported; a process that is root in the container is not root on the host; capabilities become namespaced.v1.36 user namespaces GA; concept pageADR-0003, 0008
procMount: Unmasked (KEP-4265) is stable in v1.36 and requires hostUsers: false; it is a privileged-level field under Pod Security Standards; PSS relaxes runAsNonRoot/runAsUser for user-namespace pods, and procMount only under baseline.KEP-4265; Pod Security StandardsADR-0003, 0013
agent-sandbox threat model: untrusted code must not compromise the node (gVisor/Kata via RuntimeClass); inter-sandbox traffic blocked by default; no Kubernetes API access; resource limits.agent-sandbox threat modelcontrols, ADR-0015
