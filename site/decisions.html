Decisions

Sixteen decisions, each with what it cost

ADRs are immutable once accepted; a change is a new ADR that supersedes. Expand any card for the short form; the full text is in docs/adr/ in the repository.

0001
Record architecture decisions

One file per decision; superseded, never edited. The chart's README links back so decisions travel with the artifact.

Accepted
Short form

Why

Operated for years by one person, extended by agents that were not there; a boundary whose reasoning is lost gets widened by the next convenient change.

Lost

A design doc edited in place; commit messages only.
0002
Target platform: the bare-metal k3s cluster

Ubuntu 22.04 with kernel 6.8, k3s 1.36.4, containerd 2.3.4, Cilium 1.20.1, ArgoCD 2.14.9: already meets the user-namespace requirements, so nothing is installed on the node. The repository-layout half was superseded by 0014.

Accepted
Short form

Lost

The TrueNAS lab VM with KIND (not the GitOps environment; KIND nodes complicate user-namespace pods).

Consequence

A single node: every sandbox shares one kernel; the isolation model compensates with user namespaces.
0003
Isolation: pod user namespace plus full-strength bubblewrap

hostUsers: false, procMount: Unmasked, AppArmor and seccomp Unconfined on the container, uid 1000, all capabilities dropped, read-only root. srt strict mode; weak mode kept only as a flag.

Accepted
Short form

Context

A normal pod's masked /proc stops bubblewrap's procfs mount; upstream's weak mode "considerably weakens security". Kubernetes 1.36 makes Unmasked legal when the pod has a user namespace.

Evidence

Spike: strict mode passes every check as uid 1000 in the userns pod; fails at the mount in a plain pod.

Consequence

PSS restricted is not met on three fields; the user namespace is the compensating control.

Lost

Privileged pod (escape = root); weak mode (sees the container); gVisor/Kata (not installed, no nested virt).
0004
Two sandbox kinds in one chart

workspace (Claude Code over Remote Control) and managed-agents-worker (ant). MCP gateway and Agent SDK kinds reserved, deferred.

Accepted
Short form

Why

The owner's primary use is Claude Code itself; the worker gives Managed Agents sessions a homelab to execute in. Both share the pod contract, egress model and image.

Lost

Only an MCP exec gateway; separate charts per kind.
0005
One bubblewrap layer: srt wraps the whole process

MCP servers, hooks and file tools are inside the boundary. Claude Code's inner Bash sandbox is off; stacking it would need allowNestedUserNamespaces, which weakens the outer denies.

Accepted
Short form

Context

Anthropic's sandbox-environments guide lists the whole-process wrap as the option that isolates MCP servers and hooks; the inner sandbox excludes them. Remote Control server mode honours sandbox.enabled but the two cannot stack safely.

Consequence

Per-command violation annotations are lost; srt's debug log is the record. isolation.wrap keeps the inner-only option for comparison.

Lost

Inner sandbox only; both layers; CLAUDE_CODE_PROCESS_WRAPPER (not documented for srt).
0006
Egress in two layers from one list

The same domain list renders srt's allowlist with strictAllowlist and a CiliumNetworkPolicy with toFQDNs on 443 plus DNS; private ranges refused for allowed names; no ingress.

Accepted
Short form

Why

srt only constrains what is inside bubblewrap; the entrypoint, the proxies and an escaped process see the pod's network. One source for both renderings so a mismatch fails loudly.

Residual

Domain fronting (no TLS termination); the DNS answers the policy trusts.

Lost

iptables init script (needs NET_ADMIN); CIDR-only NetworkPolicy (kept as the portable fallback); TLS-terminating proxy (enterprise step).
0007
Credentials and secrets

claude.ai login persisted on the home volume (a setup-token cannot do Remote Control); the worker's environment key in an out-of-git Secret or via ExternalSecret; optional repo-scoped GitHub PAT; no ServiceAccount token; no org API key anywhere.

Accepted
Short form

Context

Remote Control "requires a full-scope login token"; the environment key is scoped to one queue and Anthropic asks for it to live in a secrets manager.

Consequence

A compromised workspace can spend the subscription and act toward the allowlisted repositories; it cannot reach Vault, the API server or other namespaces.

Lost

ANTHROPIC_API_KEY in the workspace (no Remote Control, full-scope key); baking a login into the image.
0008
Storage

local-path PVCs for /workspace and /home/agent (idmapped mounts; NFS excluded), emptyDir /tmp and /mnt/memory, read-only root, PVCs kept on removal.

Accepted
Short form

Lost

NFS (unsupported with user namespaces); StatefulSet (Deployment + named PVCs is simpler to prune per entry); writable root (an escaped process could edit the entrypoint).
0009
Access path: Remote Control first, no ingress

Server mode with worktrees, driven from claude.ai/code or the app. No Service, no ingress. Bootstrap over kubectl exec/attach; the pod has a TTY for the one-time confirmation.

Accepted
Short form

Why

Zero inbound attack surface; the phone sees the sandbox as another machine.

Lost

code-server sharing the sandbox PVC (breaks the boundary); sshd in the pod; interactive mode under tmux (one session per process).
0010
Managed Agents: always-on worker first

v1 in-process poller sharing /workspace, one environment per trust boundary. v2: per-session pods via --on-work Jobs or the agent-sandbox controller.

Accepted
Short form

Residual

Sessions of one environment can read what the previous one left; fine for one owner, not for a shared enterprise environment.

Lost

Per-session Jobs from day one (spawner RBAC, per-session Secrets); webhook-triggered worker (needs inbound).
0011
GitOps delivery through the app-of-apps

An Application entry with two pins (chart version, image sha tag), enabled after the first publish; Secrets out of git; no PSA labels (the namespace cannot be restricted). Amended by 0016.

Accepted
Short form

Consequence

Rolling srt or Claude Code is a build-arg PR plus a tag roll, the same shape the cluster already uses.
0012
Operations and observability

Logs to Loki; debug.srt toggle (off: it prints the commands); pgrep liveness probes; resource defaults; monthly pin review; runbook items.

Accepted
Short form

Lost

A sidecar tailing srt's violation store (there is no file to tail); no probes (a hung server would sit unnoticed).
0013
Control framework alignment and enterprise porting

The controls matrix is maintained; three accepted gaps are the enterprise prerequisites (kernel per sandbox, credential brokering, signed audit); the invariants that must survive a port are listed and belong in admission policy.

Accepted
Short form

Lost

Picking one framework (controls are spread across sources); claiming PSS restricted via the user-namespace relaxation (false: Unmasked is still forbidden).
0014
Standalone repository and OCI chart

Everything in ps-claude-sandbox-agent-runtime; chart published to ghcr.io/paimonsoror/charts on chart-v* tags; homelab-charts keeps only the Application entry. Supersedes the layout in 0002; versioning rule amended by 0016.

Accepted
Short form

Context

The owner first chose the in-repository layout, then asked for a standalone project the same day, before anything was committed.
0015
North star: a control plane over pluggable sandbox substrates

Adopt kubernetes-sigs/agent-sandbox as the lifecycle layer for per-session sandboxes; add a microVM RuntimeClass when a KVM node exists; evaluate OpenShell against srt on the controls rows it changes.

Proposed
Short form

Why

The principal engineer's target decoded: Google's agent-sandbox control plane, Lambda-style microVMs and OpenShell as backends. What we built is the substrate layer; each missing piece is blocked by one concrete thing (a controller install; a KVM node).

Lost

Adopt OpenShell now (0.1.x, inverts the dependency); a custom controller; Deployments forever.
0016
Sandbox definitions as files, one per sandbox

sandboxes is a map with per-kind defaults so any number of one-sandbox values files merge; a vendored chart also reads sandboxes/*.yaml; a fleet gets one ArgoCD Application per directory from an ApplicationSet. The chart stays at 0.1.0 until there are external consumers.

Accepted
Short form

Why

Helm cannot merge lists across values files, and an OCI chart cannot discover files a consumer adds. The first rollout failed exactly on a definition that omitted what defaults now fill.

Lost

A script generating values.yaml; the ApplicationSet files generator (flattens the file); umbrella charts per team.
