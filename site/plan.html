Fleet layout

Adding a sandbox is adding a directory

In homelab-charts the ApplicationSet watches manifests/claude-sandboxes/sandboxes/*. Each directory holds a values file with one definition; common.yaml carries the image tag and the shared settings. One Application per directory, each with its own sync status and history; directories map to CODEOWNERS (ADR-0016).

manifests/claude-sandboxes/
  applicationset.yaml
  common.yaml                      image.tag · fullnameOverride · serviceAccount.create: false
  sandboxes/
    homelab/values.yaml              kind: workspace · repo · spawn: worktree
    worker/values.yaml               kind: managed-agents-worker · enabled: false

A definition states its kind and what differs from the kind's defaults. Lists replace; extraAllowedDomains are appended.

sandboxes:
  homelab:
    kind: workspace
    repo: https://github.com/paimonsoror/homelab-charts.git
    extraAllowedDomains: ["*.sororlab.dev:443"]
    remoteControl:
      spawn: worktree
      permissionMode: default

To roll the image for every sandbox, edit common.yaml. To roll the chart, targetRevision in the ApplicationSet. While the chart stays at 0.1.0, a republish moves the chart-v0.1.0 tag and needs a hard refresh or a repo-server restart.

Runbook

The operations that will actually happen

First start of a workspace

kubectl -n claude-sandbox logs -f deploy/claude-sandbox-homelab
kubectl -n claude-sandbox exec -it deploy/claude-sandbox-homelab -- claude auth login

That's it. The login is kept on the sandbox's own disk, and Remote Control connects by itself.

Login expired

kubectl -n claude-sandbox exec -it deploy/claude-sandbox-homelab -- claude auth login
kubectl -n claude-sandbox rollout restart deploy/claude-sandbox-homelab

Claude Code warns three days before expiry inside sessions.

Rotate the environment key

kubectl -n claude-sandbox create secret generic claude-sandbox-managed-agents \
  --from-literal=ANTHROPIC_ENVIRONMENT_ID=env_... \
  --from-literal=ANTHROPIC_ENVIRONMENT_KEY=... \
  --dry-run=client -o yaml | kubectl apply -f -
kubectl -n claude-sandbox rollout restart deploy/claude-sandbox-worker

Read what the sandbox denied

{namespace="claude-sandbox"} |~ "blocked|denied|violation"
kubectl -n cilium exec ds/cilium -- hubble observe \
  --namespace claude-sandbox --verdict DROPPED --last 50

srt denials need debug.srt: true; Hubble drops need nothing.

Verify the boundary from a session

curl -sI https://example.com      # 403: not allowlisted
curl -sI http://10.43.0.1         # blocked: guard + CNI
touch /etc/x                      # read-only root
echo x >> ~/.bashrc               # mandatory write deny
unshare -Ur true                  # nested userns refused
cat /proc/self/uid_map            # 0 <host uid> 65536

Stop everything

kubectl -n claude-sandbox scale deploy --all --replicas=0

Then revoke the environment key in the Console and /logout a session, or delete .credentials.json on the home volume.
