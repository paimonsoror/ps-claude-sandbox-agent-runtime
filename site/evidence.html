Rollout

The first pod, and the failure before it

The first merge produced an Application in Sync: Unknown with ComparisonError … pvc.yaml: index of untyped nil: the inline entry stated only kind, repo and remoteControl, and the first 0.1.0 package had no per-kind defaults, so persistence was nil. The CI values had carried full entries, which is why lint passed. The definitions-as-files change (ADR-0016) added the defaults; the chart was republished as 0.1.0, the repo-server restarted to drop its cached package, and the fleet layout cut over.
